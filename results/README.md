# Result Summaries

These compact CSV files contain the measured values reported in the manuscript:

- `architecture_matrix.csv`
- `architecture_deltas.csv`
- `label_reliability_audit.csv`
- `warmstart_stages.csv`
- `interface_eval.csv`
- `negative_results.csv`

The architecture matrix includes B token-state, G generic-register, C typed PAT-ER, and D warm-start/interface conditions. The manuscript tables and figures are generated from the same recorded values.
